# Program Rekap dan Analisis Nilai Matematika Kelas

## Deskripsi
Program Python sederhana untuk membaca data nilai siswa,
menghitung statistik nilai, menentukan ketuntasan,
dan menyimpan laporan hasil analisis.

## Fitur
- Membaca data nilai dari file
- Memvalidasi nilai 0–100
- Menghitung rata-rata, minimum, dan maksimum
- Menentukan ketuntasan siswa
- Menyimpan laporan ke file teks

## Cara Menjalankan
1. Buka folder proyek di VS Code.
2. Pastikan Python sudah terinstal.
3. Buka terminal VS Code.
4. Jalankan program menggunakan perintah:

python src/main.py

## Struktur Folder
- data: menyimpan data nilai
- src: menyimpan kode program
- tests: menyimpan test case
- output: menyimpan laporan hasil analisis
